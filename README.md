# DATA SHIFT

A story-driven puzzle game about restoring a QR code you can only half-remember.

Game Off 2026 · theme **SHIFT** · Python + pygame · 5 acts · English UI

> **开发状态（2026-11-10 深夜 · 最后一次更新 22:05）**
> **第一幕已经跑通**：开场碎码 → 学走路 → 学异象 → 看见老者赶走红怪 → 自由探索 → 双支线对话 →
> 10 秒空档 → 战斗 → 清屏 → 拾取 BAG / MAP → `ACT 1 — END`。
> **第二幕也能玩了**：接着第一幕的棋盘（不清空）补定时图案，紫怪会一次清掉一整条。19 个验证脚本 520 项全绿。
> 第二~五幕还没写（设计未定）。

## 这是什么

你是一个在「数据废墟」里醒来的**码序使**，不记得自己是谁。
圣坛是一张 21×21 的二维码，把它复原，你才能活下去。

**你只能照亮脚下 5×5 的一小片，而灰域 5 秒就会褪掉。**
想看，就得按下 Shift；按着 Shift 的时候你没法涂。所以每一秒都在选：先看清楚，还是先涂下去。

**而且灰域不是提示，是许可证**：光还亮着的那一格才写得对；光一褪，或者压根没照过，
落笔就是脏格（计数 + 超标扣血）。紫怪把你的定位图案清掉之后，想补回来也得重新照一遍 ——
闭着眼睛凭记忆写，是写不回去的。

## 核心机制

| 键 | 作用 |
|---|---|
| `W A S D` | 逐格移动（按一下走一格，长按 0.13s 一格） |
| `Shift` | **异象**：照亮脚下 5×5 的灰域，5 秒内逐渐褪回白色。**只在圣坛内有效** |
| `J` | 制造黑域（把脚下涂黑）。**必须在灰域还亮着的时候**，否则算脏格 |
| `K` | 消除黑域 |
| `T` | 呼喊 / 与 NPC 交互（进入范围后出现提示） |
| `B` | 拾取道具 |
| `Enter` | 对话时推进下一句 |
| `Esc` | 返回 / 退出 |

### 三种格子

| 类型 | 外观 | 含义 |
|---|---|---|
| **有效黑域** | 纯黑 | 落在本轮必涂格上，计入进度 |
| **脏黑** | 黑白相间 | 涂在了非必涂格上。会占脏格额度，超了扣血。建议按 K 擦掉 |
| 灰域 | 半透明灰 | 异象照出来的提示，告诉你这里该涂 |

**脏格数擦掉不返还。** HUD 上显示的是「本幕累计涂错过多少格」，所以每一次手滑都会留疤。

### 关键规则

- 圣坛内**只有本轮必涂格算数**，其余位置涂上去就是脏黑。平地（圣坛外）随便涂，可以当诱饵用，不参与判定
- 每幕有一个**脏格额度**（第一幕 10 格）。额度内涂错免费；**超了不判负，改成每格扣 5% 血**——
  所以要连续涂错 30 格才会死。每幕结束时圣坛**清屏**，会顺手把脏格一起抹掉
- 红怪优先吞噬黑域；**场上没有黑域时它会来打你**。每次命中扣 5% 血量，血量不会自然回复
- 每 30 秒，红怪的生成速度加快 5%（乘算）
- 阵亡 → 回到本幕检查点：血量回满、棋盘复位、红怪清空、加速复位

## 三个角色

全部用 pygame 图元现画，**没有任何图片资源**（`src/sprites.py`）。统一五层：
影子 → 剪影（深）→ 体积（暗部/亮部）→ 高光（眼/面罩/核心）→ 描边。

| 角色 | 长相 | 记忆点 |
|---|---|---|
| **码序使**（你） | 兜帽 + 收腰斗篷（下摆外张、中缝）+ 两只袖子 + 面罩亮屏 + 胸口会呼吸的核心 + 脚下影子 | 头上一块**会闪的光标** —— 他是「正在被输入的那一行」 |
| **老者** | 长袍（褶子、厚下摆）+ 腰带与结 + 兜帽 + 胡子 + 搭在拐杖上的手 + 木球拐杖 | **背对时看不见脸**，转身才露出胡子和眼睛；挥杖时杖头亮一下 |
| **红怪** | 9 顶点缓慢起伏的肉块（外圈暗、内圈亮）+ 单眼 + 3 根摆动触须 + 湿亮斑 + 一圈暗红光 | 追人时外面套**四段瞄准弧**：不看面板也知道它锁定你了 |

朝向会改面罩的位置（背对时只剩后脑一条缝），同屏的怪各自带相位、不会齐步呼吸；
一屏 14 个角色一帧约 **0.23ms**。

### 两件道具

清屏之后浮出来的 BAG 和 MAP，也是图元现画：

| 道具 | 长相 | 记忆点 |
|---|---|---|
| **BAG** | 上窄下宽的包身 + 翻盖 + 顶部提带与两个金属环 + 两个侧袋 | **金色扣**是全图唯一高光 |
| **MAP** | 左边卷成筒（两道横纹表示卷层）+ 右边展开的纸 + 折痕 + 墨线路线 | **那一点红** —— 地图上唯一的有彩色 |

掉在地上时脚下一圈金光（`_GLOW_CACHE` 预生成，不每帧新建）；捡进背包后同一套图标画进物品栏格子，只是不画那圈光。

**背包捡到之后一直背在码序使身上**：背对时整只包露在肩胛，面向镜头只剩两条肩带，左右走时从肩后探出来半个。
物品栏里只放「包里的东西」（地图）—— 背包是容器本身，不占自己的格子。

**地图**在右下角，平时是一卷收起的卷轴，按 `M` 铺开 —— 它记的是**每一幕收尾那一刻**圣坛的样子（纸上看得到 `AS OF ACT n`）。
所以：这一幕你怎么涂、紫怪清掉哪一行，地图都**不会**跟着变；只有一幕真正收尾（清屏波扫完、脏格抹净）才重新拍一张。
它的用处是「进下一幕时提醒你之前涂了哪些」，而不是实时小地图，也永远不会告诉你下一步该涂哪 ——
想知道，还得按 Shift 照异象。

**摊开地图 = 两只手都占着**：码序使会把地图捧在胸前（面朝镜头时整张纸盖住胸口，背对时纸边从两侧露出来），
这段时间 `J` 涂黑、`K` 擦除、`Shift` 异象**全都按不出来**，底部会提示 `FOLD THE MAP FIRST   [M]`。
再按一次 `M` 把图卷起来，手里空了才恢复。走路不受影响 —— 只封手，不封腿。

## 声音

没有音乐、没有外部音频文件。所有音效都是**程序合成**的（`src/sfx.py`，纯标准库，不引 numpy），
短促、干、电子——涂黑是一声「落子」、涂错是一声失谐、被咬是一声下坠、清屏发动是一记渐强的低鸣。
无声卡的机器会自动静音，不影响游玩。

## 五幕

| 幕 | 名字 | 内容 |
|---|---|---|
| ACT 1 | SHAPE | 醒来、学会异象、遇见老者、守住圣坛，拿到背包和地图 |
| ACT 2 | TIMING | 接着第一幕的码，补上**定时图案**；紫怪会一次清掉一整条线 |
| ACT 3–5 | ⬜ 待写 | |

### 第一幕流程

1. 醒来 —— 「第一幕」字幕，一段内心独白
2. 学会走路 —— 提示 WASD，走满 5 秒进入下一步
3. 学会异象 —— 提示 Shift，第一次照出灰域
4. 看见老者 —— 老者挥拐杖驱赶两只红怪，它们逃走并放狠话
5. 自由探索（**无时限**）—— 可以看死掉的红怪、看用过的道具，各触发一段独白，可选
6. 呼喊老者 —— 进入范围按 T。坛内喊 / 坛外喊是两条支线，对话不同
7. 老者离开 —— 留给你 10 秒空档
8. 战斗 —— 红怪来袭。把三个定位图案（99 格）+ 暗模块（1 格），共 **100 格**全部涂成有效黑域
9. 清屏 —— 圣坛发光 → 走进圣坛 → 圆形冲击波清光红怪
10. 奖励 —— 两格浮出「背包」和「地图」→ 按 B 拾取 → 圣坛的光扩散到整个世界

## 技术栈

- Python 3.10+
- `pygame-ce` 2.5+
- `segno` —— 生成**真正可扫**的 21×21 二维码（Version 1，纠错等级 L，容量 17 个 ASCII 字符）
- 不需要 numpy / PIL / opencv

> 二维码在开局随机生成一次，**贯穿五幕**，最后那张码是真的能用手机扫出来的。
> 校验不需要解码库：逐格比对玩家棋盘和目标矩阵是否完全相同就够了。

## 项目结构

```
config ──> grid ──> board ──┐
   │          └──> entities ─┼──> game ──> main
   └──> qr ──────────────────┘        ↑
   └──> input_state ──────────────────┘
                        ui ───────────┘（game 调 ui 画，ui 只读 game）
                         └──> sprites（角色贴图，只认 config）
```

| 文件 | 行 | 职责 |
|---|---|---|
| `src/__init__.py` | 5 | 空包标记 |
| `src/config.py` | 256 | 全部常量、颜色（含角色分层配色）、幕参数、异象/脏格/血量 |
| `src/grid.py` | 54 | 坐标换算 4 个函数 |
| `src/qr.py` | 85 | 用 `segno` 生成真二维码 + `required_cells()` 算必涂格 |
| `src/board.py` | 211 | 四态棋盘、进度、涂改、抹除、灰域计时、脏格累计、快照 |
| `src/input_state.py` | 67 | 键盘状态（只认 scancode） |
| `src/entities.py` | 323 | 玩家、怪物（红怪 `eat`/`hunt`）、老者、过场红怪、道具（**只存状态**） |
| `src/ui.py` | 815 | 所有绘制（含右侧面板、对话框、地图缩略图） |
| `src/sprites.py` | 494 | **三个角色的像素级画法**（影子/剪影/体积/高光/描边，全部图元现画） |
| `src/sfx.py` | 232 | **程序合成音效**（标准库，不引 numpy），`build(name)` → WAV bytes |
| `src/game.py` | 1174 | 11 个相位、对话推进、检查点、每帧更新、贴图时基、音效分发 |
