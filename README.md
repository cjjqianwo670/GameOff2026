## 这是什么

你是一个在「数据废墟」里醒来的**码序使**，不记得自己是谁。
圣坛是一张 21×21 的二维码，把它复原，你才能活下去。

**你只能照亮脚下 5×5 的一小片，而灰域 5 秒就会褪掉。**
想看，就得按下 Shift；按着 Shift 的时候你没法涂。所以每一秒都在选：先看清楚，还是先涂下去。

**而且灰域不是提示，是许可证**：光还亮着的那一格才写得对；光一褪，或者压根没照过，
落笔就是脏格（计数 + 超标扣血）。紫怪把你的定位图案清掉之后，想补回来也得重新照一遍 ——
闭着眼睛凭记忆写，是写不回去的。

**心声会停住整个世界**。码序者心里冒出话的时候（涂错一格、老者倒下、有东西进场……），
画面完全静止 —— 怪物也不动 —— 你按一次回车把字补完、再按一次继续。
所以犯错的代价是「被打断一下」，而不是「被遮着屏幕挨打」。同一句话 4 秒内不会重复弹，
连续涂错只停一次。

## 核心机制

| 键 | 作用 |
|---|---|
| `W A S D` | 逐格移动（按一下走一格，长按 0.13s 一格） |
| `Shift` | **异象**：照亮脚下 5×5 的灰域（**第四幕 7×7**），5 秒内逐渐褪回白色。**只在圣坛内有效** |
| `J` | 制造黑域（把脚下涂黑）。**必须在灰域还亮着的时候**，否则算脏格。第三幕的**格式格**要**按住 0.8s**；**第四幕**改成按住走、走过灰域自动连写（「扫」），没照过的格跳过 |
| `K` | 消除黑域 |
| `T` | 呼喊 / 与 NPC 交互（进入范围后出现提示） |
| `U` | **挥剑**（第三幕、拿到剑之后）。砍最近的一只怪：红怪/绿怪/紫怪一击、黄怪两击（命中还会击退） |
| `H` | **救老者**（第三幕、他倒下之后**按住**四秒） |
| `I` | **搭界丝通道**（第二幕起）：朝前方搭一条跨裂缝的临时桥（读条 1 秒、持续 5 秒），跨缝的唯一方式 |
| `E` | **时停**（第二幕起，冷却 20s）：怪物减速 70%，持续 3 秒 |
| `Q` | **冲刺**（第三幕起，冷却 5s）：向面向方向瞬移 3 格 |
| `F` | **诱饵**（第四幕起，CD 技能，冷却 25s）：脚下放一个有血量的假黑域，强吸引所有怪来攻击它 |
| `G` | **修复卷轴**（第五幕起，一次性每幕 1 个）：立即拉回一块分离中的板块 |
| `M` | **静音开关**：一次关掉全部音效与背景音乐（再按恢复） |
| `B` | 拾取道具 / 拾取界丝（站到固定黑点旁） |
| `Enter` | 对话时推进下一句 |
| `Esc` | 弹出暂停菜单（继续游戏 / **语言：English ↔ 中文** / 重新开始本幕 / 退出游戏） |

### 三种格子

| 类型 | 外观 | 含义 |
|---|---|---|
| **有效黑域** | 纯黑 | 落在本轮必涂格上，计入进度 |
| **脏黑** | 黑白相间 | 涂在了非必涂格上。会占脏格额度，超了扣血。建议按 K 擦掉 |
| 灰域 | 半透明灰 | 异象照出来的提示，告诉你这里该涂 |

**脏格数擦掉不返还。** HUD 上显示的是「本幕累计涂错过多少格」，所以每一次手滑都会留疤。

### 关键规则

- 圣坛内**只有本轮必涂格算数**，其余位置涂上去就是脏黑。平地（圣坛外）随便涂，可以当诱饵用，不参与判定
- 每幕有一个**脏格额度**（第一幕 10 格）。额度内涂错免费；**超了不判负，改成每格扣 5% 血**——
  所以要连续涂错 30 格才会死。每幕结束时圣坛**清屏**，会顺手把脏格一起抹掉
- 红怪优先吞噬黑域；**场上没有黑域时它会来打你**。每次命中扣 5% 血量，血量不会自然回复
- 每 30 秒，红怪的生成速度加快 5%（乘算）
- 阵亡 → 回到本幕检查点：血量回满、棋盘复位、红怪清空、加速复位

## 三个角色

全部用 pygame 图元现画，**没有任何图片资源**（`src/sprites.py`）。统一五层：
影子 → 剪影（深）→ 体积（暗部/亮部）→ 高光（眼/面罩/核心）→ 描边。

| 角色 | 长相 | 记忆点 |
|---|---|---|
| **码序使**（你） | 兜帽 + 收腰斗篷（下摆外张、中缝）+ 两只袖子 + 面罩亮屏 + 胸口会呼吸的核心 + 脚下影子 | 头上一块**会闪的光标** —— 他是「正在被输入的那一行」 |
| **老者** | 长袍（褶子、厚下摆）+ 腰带与结 + 兜帽 + 胡子 + 搭在拐杖上的手 + 木球拐杖 | **背对时看不见脸**，转身才露出胡子和眼睛；挥杖时杖头亮一下 |
| **红怪** | 9 顶点缓慢起伏的肉块（外圈暗、内圈亮）+ 单眼 + 3 根摆动触须 + 湿亮斑 + 一圈暗红光 | 追人时外面套**四段瞄准弧**：不看面板也知道它锁定你了 |

朝向会改面罩的位置（背对时只剩后脑一条缝），同屏的怪各自带相位、不会齐步呼吸；
一屏 14 个角色一帧约 **0.23ms**。

### 三件道具（BAG / MAP / SWORD）

清屏之后浮出来的 BAG / MAP（和第三幕的剑），也是图元现画：

| 道具 | 长相 | 记忆点 |
|---|---|---|
| **BAG** | 上窄下宽的包身 + 翻盖 + 顶部提带与两个金属环 + 两个侧袋 | **金色扣**是全图唯一高光 |
| **MAP** | 折过的羊皮纸 + 右折压暗 + 中缝 + 路线墨点 + 金色叉 | **金色叉**是唯一高光 |

掉在地上时脚下一圈金光（`_GLOW_CACHE` 预生成，不每帧新建）；捡进背包后同一套图标画进物品栏格子，只是不画那圈光。

**背包捡到之后一直背在码序使身上**：背对时整只包露在肩胛，面向镜头只剩两条肩带，左右走时从肩后探出来半个。
物品栏里只放「包里的东西」—— 背包是容器本身，不占自己的格子。

**地图（2026-11-22 回归，纯收藏）**：第一幕收尾和 BAG 一起掉，捡进物品栏占一格，
**没有按键、不封操作、不做幕账**。拾取时那句 `MAP — out past the edge. A second altar, still holding a code.`
只埋「第二圣坛」的位置线索，不提示下一步该涂哪 —— 想知道，还得按 Shift 照异象。

~~旧版地图（2026-11-14 已删，留档）~~：按 `M` 摊开一张「每一幕收尾那一刻」的定格照，

## 声音

没有外部音频文件。音效和**背景音乐**都是**程序合成**的（`src/sfx.py`，纯标准库，不引 numpy）：
音效短促、干、电子——涂黑是一声「落子」、涂错是一声失谐、被咬是一声下坠、清屏发动是一记渐强的低鸣；
背景音乐是每幕一段 12 秒无缝循环的环境层（低频 drone + 心跳脉冲 + 稀疏点缀，第三、四幕加噪声扫描底），
刻意不做旋律，不抢叙事字幕。按 `M` 静音。无声卡的机器会自动静音，不影响游玩。

## 五幕

| 幕 | 名字 | 内容 |
|---|---|---|
| ACT 1 | SHAPE | 醒来、学会异象、遇见老者、拼四块圣坛，拿到背包 |
| ACT 2 | TIMING | 接着第一幕的码，补上**定时图案**；紫怪会一次清掉一整条线 |
| ACT 3 | FORMAT | 老者回来，替你补上**格式信息**（那张码的「读法」）。他得走过去站在格子上才写得出来；**黄怪**冲他来（认为是我们偷的）：**它们咬一口就打断他写字**，所以你必须去砍；他会被打倒，按住 `H` 四秒救起来，起身那一下会震开身边的黄怪 |
| ACT 4 | SWEEP | **数据区**（约 100 格）。动词换成「扫」：按住 `J` 走过照出来的灰域就自动制造黑域，没照过的格直接跳过（不写、也不算脏格）。异象扩到 7×7，可灰域还是 5 秒就褪 —— 照一次覆盖不完，得挑路线。紫怪回潮（4 只/分）。**老者回来了**，只补骨架（定位/定时/暗模块/格式），数据区不碰 |
| ACT 5 | READ | **不涂新格**。侵蚀吃掉 9 个码字，玩家把错误压进**容错容量**（3 个码字）就能被读出来。**按码字算，不按格算**：一格错也毁一个码字，所以「可以整块留白 3 块」≠「可以错 3 格」。压住 3 块 → 一道光把码从上到下读一遍 → `IT READS: XXXXXXXX`。**老者也在场**：他只补骨架（定位/定时/暗模块/格式），数据区一格不碰。**结局会把这张码印成能用手机扫的样子**（`IT READS: YOU WERE HERE`） |

### 第一幕流程

1. 醒来 —— 「第一幕」字幕，一段内心独白
2. 学会走路 —— 提示 WASD，走满 5 秒进入下一步
3. 学会异象 —— 提示 Shift，第一次照出灰域
4. 看见老者 —— 老者挥拐杖驱赶两只红怪，它们逃走并放狠话
5. 自由探索（**无时限**）—— 可以看死掉的红怪、看用过的道具，各触发一段独白，可选
6. 呼喊老者 —— 进入范围按 T。坛内喊 / 坛外喊是两条支线，对话不同
7. 老者离开 —— 留给你 10 秒空档
8. 战斗 —— 红怪来袭。把三个定位图案（99 格）+ 暗模块（1 格），共 **100 格**全部涂成有效黑域
9. 清屏 —— 圣坛发光 → 走进圣坛 → 圆形冲击波清光红怪
10. 奖励 —— 浮出「背包」→ 按 B 拾取 → 圣坛的光扩散到整个世界

## 技术栈

- Python 3.10+
- `pygame-ce` 2.5+
- `segno` —— 生成**真正可扫**的 21×21 二维码（Version 1，纠错等级 L；字母数字模式 25 字符 / 含小写只剩 17 字节）
- 不需要 numpy / PIL / opencv

> 这张码的内容是**固定的**：`YOU WERE HERE`。它从封面、棋盘一路贯穿五幕，最后在终幕页被印成
> **能用手机扫出来**的样子 —— 扫出来就是这句话。
> 校验不需要解码库：逐格比对玩家棋盘和目标矩阵是否完全相同就够了。

## 明确不做

- 不做多人、不做联网、不做账号
- 不做粒子 / 残影（角色的呼吸、肉块起伏、触须摆动是 sprite 内部每帧重算的多边形，不是粒子系统）
- 不用 asyncio
- 不做鼠标涂色（鼠标只点菜单）
