# DATA SHIFT

A tiny keyboard-only puzzle game: restore a corrupted QR code before the red eroders eat it.

Game Off 2026 entry · theme **SHIFT** · Python + pygame · **no external assets** (no images, no audio).

一个只用键盘的极简解谜小游戏：限时把中心 21×21 的「二维码」复原到关卡要求，同时把噪声压在上限内；
猩红色的「侵蚀体」从外围环不断涌入，每吃掉一个已涂黑的格子就自毁。5 关逐关解锁。

棋盘是 25×25 的纯白网格，21×21 的目标区**正居中**，四边各留 2 格。

## 运行 Run

```bash
pip install pygame-ce     # 或 pygame，两者都能跑
python src/main.py        # 从项目根执行；也可以 python -m src.main
```

- Python 3.10+
- 本仓库在 PyCharm 里的解释器是 `.venv`（Python 3.11.5 + pygame 2.6.1），入口 `src/main.py`
- 代码在 `src/` 包里，模块之间用 `from src.xxx import ...`；`src/main.py` 顶部有路径引导，
  所以 `python src/main.py` 和 `python -m src.main` 两种方式都能启动
- 窗口按桌面可用空间自动等比缩放（内部逻辑画布固定 1000×1000，画完再整帧缩放，判定逻辑不受影响）
- 无存档：关掉游戏，关卡解锁进度归零

## 操作 Controls

| 键 | 作用 |
|---|---|
| `W` `A` `S` `D` | 逐格移动（按下即走一格，长按每 0.13s 走一格） |
| `J`（或空格） | 涂黑脚下格子；**按住 J 移动 = 边走边涂** |
| `K` | 抹除脚下格子（0.25s 灰色塌陷动画） |
| `R` | 局中：重开本关；结算页：失败重试 / 通关进下一关 |
| `Enter`（含小键盘） | 开始页进入选关页；选关页进入所选关卡 |
| `←` `→` / `A` `D` | 选关页切换高亮（移不出已解锁范围） |
| `Esc` | 局中/结算 → 选关页；选关页 → 开始页；开始页 → 退出 |
| `F1` | 调试信息（FPS / 坐标 / 目标格数 / 同屏怪物数） |

**鼠标只允许点菜单按钮**（开始页的 START、选关页的 1~5），游戏进行中没有任何鼠标操作。

### 记忆层（第 1 关起）

**灰色提示只在走过的地方亮着。** 起手只有脚下 5×5 一小片，其余全是白的——你完全不知道那里该不该涂。
每走到一格，以他为中心的 5×5 灰影**永久**亮起（`SEEN_RADIUS=2` 可调，1 就是 3×3）。

这是整个玩法里唯一的取舍来源：**看地图要花时间，而时间是从涂色里拿走的**。
补一格不再"不要钱"——走过去的那几秒，你看不见别的地方。

由 `config.LEVELS[i]["seen"]` 逐关开关（现在是第 1 关开、2~5 关关，方便单独验证手感）；
关掉时 `Board.is_seen()` 恒为真，等于老玩法，代码路径完全一样。

### 侵蚀体

- **红怪**（猩红）：撞到黑格，只吃掉那**一格**
- **紫怪**（紫色，第 2 关起）：**只挑「完成度最高的那一行」**——算出每一行已涂对的目标黑格数，取最大的那一行，
  撞上去把这一行的黑格全清成白色。灰色提示会重新出现，等于这一行白涂了，必须重来。
  第 2 关共 3 只，在开局前 2 分半内的随机时刻从虚线上进入
  （`config.PURPLE_MODE` 可以切回 `"nearest"` 的旧行为：撞最近黑格、清随机一行）

前 30 秒（`PHASE 1`）可以涂整个 25×25 网格；30 秒后外围锁死（已涂黑的保留，没涂的不能再涂），
只能操作中心 21×21 目标区（外围那 2 圈变暗），同时弹出 1 秒 `PHASE SHIFT` 遮罩。

**进关有 3.1 秒开场动画**：完整二维码先以纯黑铺出来（最初 0.2 秒只有暗模块 `(13,8)` 一格是黑的）→
停留 1.5 秒后抖六下（前 3 下在震碎之前）→ 每个黑格炸成一块碎片四散、被重力拉出屏幕
（1.2 秒，此时网格全白）→ 灰色提示层淡入（0.4 秒）。这段时间**不计时、不出怪、不能涂**，动画结束才开始跑表。

评级：`S`（复原 ≥95% 且噪声 ≤3）／`A`（噪声 ≤ 上限 40%）／`B`（通关）／`F`（失败）。

## 叙事 Narrative

你是一个忘记自己是谁的「码序使」，靠手感复原一张张二维码。全部台词只有 22 行，
集中在 `src/story.py`（改文案只动这一个文件）。投放点共五处：

- 标题页：`YOU WAKE UP MID-SENTENCE.`
- 选关页：`SELECT FRAGMENT` + 五个碎片名（`FRAGMENT ?? / UNREADABLE` 是还没读懂的那一片）
- 每关开场一句（底部字幕条，在开场动画期间显示，不占可玩时间）
- 局中一次性一句：第 2 关第一只紫怪登场时弹 `TOO PRECISE TO BE NOISE.`，只弹一次
- 结算一句；失败统一 `NOT YET READABLE.`
- 开局前 0.2 秒只有暗模块 `(13,8)` 一格是黑的 —— 每次开局都从那一格开始

## 项目结构 Structure

按职责拆成 10 个模块 + `__init__.py`，统一放在 `src/` 包里，依赖单向，**没有循环 import**：

```
config ──> grid ──> board ──┐
   │          └──> entities ─┼──> game ──> main
   └──> qr ──────────────────┘        ↑
   └──> input_state ──────────────────┘
                        ui ───────────┘（game 调 ui 画，ui 只读 game）
```

| 文件 | 行数 | 职责 |
|---|---|---|
| `src/__init__.py` | 5 | 空包标记，让 `from src.xxx import ...` 成立 |
| `src/config.py` | 145 | 所有常量、颜色、关卡表、开场动画参数、记忆层参数（连 pygame 都不 import） |
| `src/grid.py` | 41 | 坐标换算：`cell_to_rect` / `pos_to_cell` / `cell_center` / `to_target` |
| `src/qr.py` | 65 | 程序化生成 21×21「形似 QR」目标矩阵 |
| `src/board.py` | 150 | 棋盘状态、统计、涂改、抹除计时、`best_row()`、`seen` 记忆位图 |
| `src/input_state.py` | 49 | 键盘状态（只认 `scancode`，与输入法无关） |
| `src/entities.py` | 161 | `Player`（格子步进）+ `Monster`（寻路啃食，红/紫两种模式） |
| `src/ui.py` | 408 | 所有 `draw_*`，函数第一个参数是 `Game`，只读不改状态 |
| `src/game.py` | 465 | `Game`：状态机 / 回合 / 关卡推进 / 开场动画 / 每帧更新 |
| `src/story.py` | 58 | 全部叙事文本（22 行台词） |
| `src/main.py` | 67 | 开窗口 + 主循环（含直接运行脚本时的路径引导） |

共 1614 行。**改数值只动 `config.py`，改界面只动 `ui.py`，改规则只动 `game.py`。**
