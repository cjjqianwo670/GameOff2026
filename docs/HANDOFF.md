## 3. 状态机与键位

### 状态机（✅ 已实现，共 13 个相位）

第一幕内部的阶段（同一「幕」里切换，不是四个顶层状态）：

```
TITLE
  └─> INTRO          醒来：3.1s 碎码动画（结尾只留脚下 5×5）+ 独白
       └─> TUTORIAL  提示 WASD → 走满 5 秒 → 提示 Shift
            └─> FREE_ROAM   自由探索（无时限，可看死怪 / 道具，可选）
                 └─> DIALOG     按 T 呼喊老者，回车逐句（坛内 / 坛外两条支线）
                      └─> GAP      老者离开，10 秒空档
                           └─> BATTLE   红怪来袭，涂满 100 格必涂格
                                └─> CLEAR    圣坛发光 → 走进圣坛 → 冲击波清场
                                     └─> REWARD   两格浮出道具 → 按 B 拾取 → 光扩散
                                          └─> END
任意相位 ──(血量归零)──> DEAD ──(按 R / Enter)──> GAP 起点（检查点）
```

- **共 13 个相位**：`TITLE / INTRO / TUTORIAL / FREE_ROAM / DIALOG / GAP / A2_OPEN / BATTLE / DEAD / CLEAR / REWARD / SCAN / END`
（`A2_OPEN` = 第二幕 2.6 秒开场；`SCAN` = 第五幕收尾那 2.6 秒光束，见 §4.24）
- 阵亡 → `DEAD` → 回到 `GAP` 起点（检查点）：血量回满、棋盘复位、红怪清空、加速复位、**累计脏格也还原**
- `BATTLE` 没有总时限。压力来自「每 30 秒刷怪加速」和「血量只减不增」
- **两条教程逃逸阀**（否则会把玩家锁死）：走进老者 `CALL_RANGE_PX` 内直接进 `FREE_ROAM`；
在坛外连按 `Shift` `ANOMALY_MISS_LIMIT=3` 次都没照出东西，同样放行
- 旧版的 `PLAY` / `RESULT` 已被上面这套取代，残留代码 2026-11-12 已清干净

**和旧版的区别**（旧版：静态码 → 抖 → 碎片按重力往下掉）：

1. **印**：扫描线逐行印出。信息量是逐步给的，玩家会先看见三个角，再看见中间 —— 比整张跳出来好读。
2. **颤**：抖动保留，另加「随机模块闪白」（`_intro_glitch`，坐标+时间哈希，不存状态）。像信号不稳，不像在晃镜头。
3. **塌**：收敛点从**屏幕中心**改成**玩家脚下**（`g.burst_center`）。实测出生点在定位图案里之后，
从屏幕中心炸开会显得「我掉到了角落」；从脚下收回脚下，才和「只剩脚边一小片」是同一件事。
4. **色**：碎片塌陷途中 黑 → 灰(`C_MIRAGE`) → 白，正好是**异象那一片灰**的颜色。塌完就是那片灰。
5. **裁**：碎片和冲击环都 `set_clip` 到棋盘矩形。不裁的话会糊到右侧面板和褐色背景上，看着像 bug。

⚠️ 碎片是 `[x, y, vx, vy, scale, k, death]` 七元组，`x/y` 是**中心点**（不是左上角）。
`ui._draw_debris()` 直接拿它算 rect。改结构要两边一起改。

是**框占半屏 + 每次都要停车读**，而涂错、被咬这种事一分钟发生十几次。

### 4.12 音效（`src/sfx.py`，2026-11-11 新增）

用户要求加音效但**没写音效文档**，所以是我自行设计的（用户说「先自己发挥」）。全部**程序合成**：
`array` + `math` + `wave`（标准库，**没有 numpy**），`build(name)` 返回 WAV bytes，由 `Game._Audio` 包成
`pygame.mixer.Sound` 按名播放。不落盘、零版权、零新依赖，仓库自包含。

| 音效名 | 触发 | 声音意图 |
| --- | --- | --- |
| `paint` | 涂黑（圣坛内必涂格 / 平地诱饵） | 低频方波「落子」滴答 |
| `stain` | 涂错（脏格） | 失谐的短促错音 |
| `erase` | K 抹除 | 频率上滑的「收回」 |
| `anomaly` | Shift 异象照出灰域 | 带颤音的扫描气声 |
| `hurt` | 被红怪咬 / 脏格超额度扣血 | 下坠的粗方波 |
| `red_die` | 红怪吃掉黑域自毁 | 「啪」+ 下滑 + 噪声 |
| `pickup` | 拾取 BAG / SWORD | 两声上扬的小铃 |
| `clear` | 圣坛发动（进 wave） | 渐强的咻 + 一记低鸣 |
| `ui` | 对话翻页 | 极轻的「咔」 |
| `staff` | 老者挥杖驱赶红怪 | 一下呼啸 |

几条约定：

- `_Audio.play()`\*\* 永不报错\*\*：mixer 初始化失败（无声卡 / 权限）时 `enabled=False`，所有 play 变 no-op。
所以测试环境 `SDL_AUDIODRIVER=dummy` 下游戏照常跑，音效静默。
- **按住键不会连响**：`paint` 依赖 `board.paint()` 返回非 `None`（格子已黑就返回 None）；`erase` 依赖
`start_erase()` 返回 True（格子已 ERASING 就返回 False）。所以长按 J/K 只有第一下出声。
- 音量基准表在 `sfx._GAIN`（0\\\~1），听不惯改这个，不用重做波形。
- 每个音效都短（0.03\\\~0.55s）、干、电子，符合「数据废墟」而不是「自然世界」。

### 4.16 第二幕的「核心」：破坏即分离（2026-11-15）

作者定：定位图案（finder）中心的 3×3 黑块叫「核心」。第二幕起，怪物破坏核心（哪怕 1 格），
对应板块就与其他板块分离。

| 项 | 规则 |
| --- | --- |
| 核心在哪 | 三个定位图案各一个 3×3（`qr.finder_cores()` → `{TL, TR, BL}`），**右下角没有核心** |
| 破坏来源 | 红怪啃单格（`on_core_damaged`）、紫怪清整行/列（`on_line_core_damaged`） |
| 分离 | `board.detach_board(name)`：板块被推开 1 格（`push_frac` 返回 1.0），核心标记转红闪烁。**推开的方向让这块板同时和它两个相邻的板之间各裂开一条缝** |
| 分离的代价 | 该板块的必涂格**不再计入进度**（`progress()` 跳过 `detached` 里的板块）→ 补不好核心就过不了关 |
| 合回 | `update_core_reattach()` 每帧查：9 格核心全 VALID → `reattach_board()` 滑回原位 |

**编号与相邻**（作者 2026-11-15 定的语义，`config.BOARD_NUM` / `BOARD_ADJACENT`）：

- 板块 1 = BL（左下）· 2 = TL（左上）· 3 = TR（右上）· 4 = BR（右下），顺时针。
- 每块有两个邻居，围成环 1-2-3-4-1：1 相邻 2（上）和 4（右）、2 相邻 1（下）和 3（右）、
3 相邻 2（左）和 4（下）、4 相邻 1（左）和 3（上）。
- 核心被破坏 → 该板块**和它两个相邻的板都分离**（不是「自己飘走」）。视觉上它被推开一格，
因为每块只贴两个邻居，推开一格自然就在这两个接缝上各裂开一条缝。
- 右下角（板块 4）没有核心，**永远不会自己分离**，是「不动的锚点」。

关键实现点（和第一幕的「没接回」是两回事，别混）：

- 第一幕的「没接回板块」= 站不上、写不了（`open_boards` 里没有）。
第二幕的「分离板块」= **还在 **`open_boards`** 里，能站、能写**，只是进度不算、视觉被推开。
否则「补满核心 9 格就合回」这条根本做不到 —— 站不上去就没法补核心，软锁。
- 所以 `progress()` 里单独判 `detached`，`can_stand` / `in_altar` **不动**（分离的板块照样能踩能涂）。
- 检查点快照里存了 `detached`（回档后分离状态跟着还原）。
- 核心标记：`ui._draw_core_marks()`，完好板子淡蓝四角（`C_CORE`），分离板子红、随 `anim_t` 呼吸闪烁。
只在 `act >= 2` 且 BATTLE / SCAN / A2\\\_OPEN 相位画。
- 心声：分离 `CORE_BROKEN`（"The core broke. That slab is loose."）、合回 `CORE_FIXED`，都走飘字不冻世界。

### 4.22 心声会冻住整个世界，按回车才继续（2026-11-12）

> **2026-11-14 更新**：这条只对**叙事类**成立（见 §4.9 的两套字幕）。
> 反馈类已改成 `mumble()` 飘字，不再冻世界 —— 作者反馈「每次玩都被心声打断」。

作者原话：「在码序者的心声的时候整个游戏静止，然后需要玩家按回车退出心声（也就是继续游戏）。
理由是有时候玩家犯错，然后突然出现心声遮住屏幕了，怪还在打你，体验感很差。」

实现只有三处，但**顺序很关键**：

| 位置 | 做什么 | 为什么是这个位置 |
| --- | --- | --- |
| `Game.update()` 最前面 | `if self.mono_hold: self.mono_elapsed += dt; return` | 必须在 `anim_t += dt` **之前**。放后面的话「贴图还在动」，放中间的话这一帧里怪已经打过你了 |
| `Game.handle_event()` 在 `DIALOG` 之后 | 暂停中只认回车 / `R` / `ESC`，其余 `return` | 世界停着，任何操作都不该生效 |
| `ui._draw_monologue()` 的条件 | `mono_text and (mono_hold or mono_t > 0)` | ⚠️ 暂停时 `mono_t` 恒为 0，只判 `mono_t > 0` 会让心声**一个字都画不出来** —— 第一版就是这么错的，截图才发现 |

`mono_t` 的语义变了：**不再是「寿命」，而是「关闭后的淡出剩余」**。
打字机改用 `mono_elapsed`（出现多久），寿命由玩家按几次回车决定。

同句冷却（`MONO_REPEAT_GAP=4.0`）：作者选的范围。`say()` 里判「同一句 + 冷却中 + 当前没在暂停」就直接吞掉。
冷却从**关闭那一刻**开始算，不是从说出那一刻 —— 否则玩家读得慢，冷却是白给的。

> ⚠️ 改这里的坑：**测试会大面积假死**。所有 `for _ in range(n): g.update(1/60)` 的循环，
> 一旦中途冒出心声就再也不动了，而且不报错、只是断言一个个变红。
> 所以 `_act1_common` 加了 `auto_mono(g)`，**全部**验证脚本的推进循环都包了一层。
> 写新测试时**记得在推进时间的循环里带上它**，否则你会花半小时排查一个不存在的 bug。

### 4.23 第四幕：扫（data area / 2026-11-14）

**为什么这一幕是「换动词」而不是「再加一层结构」**：QR v1 只有四层（定位 → 定时 → 格式 → 数据），
前三幕把前三层用完了。剩下的是**数据区约 100 格，没有语义**——照现在「按住一下涂一格」的做法，
第四幕就是再搬一次砖，而且没有任何新信息。所以这一幕**不动图案、不引新角色**，只换动作
（唯一的变化是**老者回来了**，但只补骨架，见下表两行）：

| 项 | 实现 | 备注 |

## 5. 踩过的坑（别重犯）

> 下面 14 条**全部仍然有效**——它们讲的是 pygame、scancode、坐标、性能、资源回收，跟玩法改版无关。
> 唯一需要打折的是第 2 条的**举例**（`qr.py` 要换掉），但**教训保留**。

1. `SC_ENTER`** 必须是 40**。原来写成 28，而 SDL2 里 28 是字母 **Y** → 按回车没反应、按 Y 反而能进关。
固定表：字母 A=4…Z=29，数字 1=30…0=39，Return=40，Esc=41，Space=44，F1=58，←=80，→=79。**别凭记忆敲数字。**
2. **任何重试循环都必须有次数上限**（⚠️ 举例已作废，教训保留）。
旧 `generate_target()` 的重摇没有上限，信息区填充率 0.5 够不到 0.70 的阈值 → 无限递归 → `RecursionError`。
换成 segno 之后不再需要重摇，但只要写 `while` 重试，**一律带上限**。
3. **切到「另一个整屏」时，第一件事是铺底**：旧 `draw_result()` 少了 `s.fill(C_BG)`，结算页会叠在上一帧棋盘上。
这个 bug 只有「先画一帧游戏再切结算」才暴露。（那个函数 2026-11-12 已删，**教训留用**：新加整屏界面照做。）
4. **白底不要逐格 **`fill`** 576 次**：一次铺满整块网格，再补锁定格（实测 draw 9.2ms → 5.2ms）。
5. `claims`** 占用表必须在四条路径回收**：吃掉 / 改道 / 超时自毁 / 结算。漏一条会越积越大，后续的怪误以为“全被占了”。
6. **鼠标坐标要 **`/ self.scale`（窗口被等比缩放过），否则点击位置整体偏移。
7. pygame-ce 2.5.8 **没有** `set_window_size` / `get_scancode_from_key`，别指望运行时换算或改窗口大小。
8. **代码在 **`src/`** 里就要用 **`from src.xxx import ...`。曾经混着 `from src.board` 和 `from config`，
结果 `python src/main.py` 报 `No module named 'src'`、`python -m src.main` 报 `No module named 'config'`，
**两种启动方式同时挂**。改 import 时全套一起改，别只改一半。
9. **开场碎片不能画成纯黑**：黑方块飞出白网格、落到深色背景上就完全看不见，只剩描边像空心框。
用 `C_MISSING` 实心 + `C_CELL_LINE` 描边 1px，两种底色上都读得出来。
10. **开场动画期间别画玩家**：角色会浮在碎码中间很怪。`ui.draw_world()` 里 `if g.intro_t <= 0: draw_player(...)`。
11. `INTRO_FALL`** 必须覆盖最坏下落时间**：重力 1800 时，最上一行、带 120 向上初速的碎片要约 1.18s 才出屏，
所以取 1.20s。否则灰码淡入时天上还有碎片，看起来像没碎干净。
12. **整帧抖动不要改绘制坐标**：先把画面正常画到 `canvas`，再用 `apply_shake()` 借 `shake_buf` 中转、
按偏移重贴一次，四周露 `C_BG`。用 `sin` 的话帧率一抖、采样点就变，会忽大忽小，所以用固定序列。
13. **改网格尺寸只动 **`config.py`** 三个常量**：`GRID_N`、`GRID_ORIGIN`、`TARGET_OFFSET`（外加 `GRID_PX` 的注释）。
现在是 25×25：`GRID_ORIGIN=(70,130)`、`TARGET_OFFSET=(2,2)`。
注意原点**不再居中**了：画布加宽到 1360 之后，网格是**靠左**摆的（左边留 70、右边留给面板），
所以别再套 `(画布宽 − 25×28)/2` 那个公式。
`GRID_N − TARGET_N`** 必须是偶数**，21×21 才可能正居中；24×24 时差 3，只能左/上留 1 格。
14. `InputState.down()`** 绝不能用 **`pygame.key.get_pressed()[sc]`** 兜底**（2026-11-11 踩到，症状：站着不动按回车就把脚下涂黑）。
那个数组在部分环境下按 **keycode** 索引，而这里传的是 **scancode**，两套号会在数值上撞车：
**按「回车」→ keycode 13 → 被当成「J」（scancode 13）→ 涂格。**
字母里只有 J 会撞（其余 scancode 在 keycode 空间里对应 Ctrl 组合，平时按不到），所以症状很怪：**只有回车会误涂**。
现在 `down()` **只读事件集合 **`held`；防按键卡死靠 `WINDOWFOCUSLOST` / `WINDOWFOCUSGAINED` 清空，不靠轮询。
⚠️ 这类 bug **自动化测试很难抓到**：合成事件只走 `held`，轮询那条路在无焦点环境恒为 False。
写输入相关的断言时，要**主动伪造一个「串键」的 **`get_pressed` 去卡它（`_verify_act1_keys.py` 里就是这么做的）。

## 7. 铁律

- **依赖：**`pygame`** + **`segno`** + 标准库**。不引入 numpy / PIL / opencv（numpy 对 441 格没有任何必要）
- 不用 asyncio；普通 `while` + `clock.tick(60)`
- **不做粒子 / 残影**。**震屏只有一处例外：开场动画**，别处一律禁止。
⚠️ 2026-11-10 起**怪物不再是一个 **`draw.circle`：三个角色改在 `sprites.py` 里逐层画
（红怪 = 9 顶点缓慢起伏的肉块 + 眼 + 触须）。这是用户明确要求的例外，
但**没有放宽「不做粒子」** —— 所有抖动都是每帧重算一个多边形，不存粒子对象、不留残影、不做拖尾
- **界面全英文**。分两档：
  - **HUD、按钮、系统提示 → 全大写**（`NOISE 3` / `PRESS T`）
  - **剧情台词、独白、对话 → 正常大小写**（一整句全大写的英文读起来很累，而且没有语气）
- 字体只建一次（`pygame.font.Font(None, size)`）。**英文字体够了，不需要外挂字体文件**
- 键盘只用 `event.scancode`；初始化 `pygame.key.stop_text_input()`；`WINDOWFOCUSLOST` 清空按键集合
- 涂改只作用于**脚下这一格**；鼠标只允许点菜单按钮
- 数值只在 `config.py`，画法只在 `ui.py` + `sprites.py`（角色），规则只在 `game.py`
- 代码都在 `src/` 包内，import 一律 `from src.xxx import ...`
- **脏格计数必须是「本幕累计值」**，不是「当前画面上的脏格数」。擦掉不返还，见 §4.4
- **异象只在圣坛内生效**；平地上按 Shift 不给灰域（这是叙事设定，也是玩法边界）
- 二维码用 `segno.make(content, version=1, error="l")`，**把 version 和 error 写死**，别自动选版本
- **音效必须程序合成**（`src/sfx.py`，标准库），不引 numpy、不落盘素材。`_Audio.play()` 要能静默降级，别让无声卡拖垮游戏
