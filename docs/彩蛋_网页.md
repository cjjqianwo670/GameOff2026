## 3. DNS 记录（9 条，2026-11-22 实测生效）

| # | 类型 | 主机记录 | 值 | 说明 |
| --- | --- | --- | --- | --- |
| 1–4 | A | `@` | `185.199.108.153` / `.109` / `.110` / `.111` | GitHub Pages 固定 4 个 IPv4 |
| 5–8 | AAAA | `@` | `2606:50c0:8000::153` / `8001` / `8002` / `8003` | 同上，IPv6 |
| 9 | CNAME | `www` | `cjjqianwo670.github.io` | **正确值**，见下方偏差 |

- 解析线路全部「默认」，TTL 600 秒（阿里云免费版最短）
- 实测 `he-r.cn` 的 A 记录返回的就是上面 4 个 IP，`www` 的 CNAME 也已生效

### ⚠️ 已知偏差：`www` 的 CNAME 目标多了一个 `j`

阿里云里第 9 条现在填的是 **`cjqjianwo670.github.io`**（`cjqj...`），真实账号是 **`cjjqianwo670`**。

**它目前仍然能打开**（实测 `https://www.he-r.cn` 200）。原因是：GitHub Pages 是靠请求里的
**Host 头**去找站点的，CNAME 只负责把域名解析到 GitHub 服务器的 IP；而 `*.github.io` 是泛解析，
随便一个不存在的子域也能解析到 Pages 的 IP。所以「错着也能跑」。

但这是**偶然能跑**，不是正确配置，建议择机把第 9 条改成 `cjjqianwo670.github.io`。

改的时候注意：

- 改完 GitHub 可能会重新跑一次 DNS 校验（甚至重签证书），**别在改完立刻删记录或点 Remove**
- 改完用 `nslookup www.he-r.cn` 确认新目标生效，再访问一次确认 200
- 证书是 `he-r.cn` + `www.he-r.cn` 一起签的，改 DNS 期间出现短暂证书警告属正常，等几分钟

## 4. 怎么改网页

**方式 A：GitHub 网页直接改（适合改文案）**

打开 `https://github.com/cjjqianwo670/cjjqianwo670.github.io` → 点 `index.html` → 铅笔图标 → 改 → `Commit changes`。
约 1–2 分钟后生效。

**方式 B：本地改完 push（推荐，尤其做动画/Canvas）**

```bash
git clone https://github.com/cjjqianwo670/cjjqianwo670.github.io.git
cd cjjqianwo670.github.io
# 改 index.html / 加 css js img
git add . && git commit -m "彩蛋：老者记忆第一版" && git push
```

本地双击 `index.html` 就能预览，比在网页上盲改快得多。

**生效时间**：push 后 GitHub 自动构建，30 秒~2 分钟；浏览器可能因缓存看到旧版 —— `Ctrl+F5` 或开无痕窗口验证。
构建状态看仓库 **Actions** 标签（Deploy from a branch 模式也会有内部构建记录）。

## 5. 硬约束（动之前必须知道）

1. **纯静态**。GitHub Pages 不发证书以外的东西，也不执行服务端代码：没有 PHP、没有数据库、没有表单提交。
   要做「记忆解锁」这种有状态的东西，只能用前端存储（`localStorage`）或外部服务。
2. **网页地址不能变长**。`config.QR_CONTENT = "https://he-r.cn"` 是 **15 字节**，v1-L 字节模式上限 **17 字节**。
   想换地址（比如 `https://he-r.cn/memory`）会直接超限 → **必须先在 `config.py` 里数字节**，
   而且要同步改 `docs/DATA_SHIFT_第五幕英文文案.md`、`story.END_LINE` 的展示、以及三处测试
   （`_verify_act1_qr` / `_verify_act5_flow` / `_smoke_full_run`）。
   最省事的做法：**死守 `https://he-r.cn` 不改**，页面内容怎么变都行。
3. **`CNAME` 文件不能删、不能改内容**。它是域名绑定的锚，删了下次部署域名会掉回 `cjjqianwo670.github.io`。
4. **别往仓库里放密钥**。仓库是公开的，Pages 发布出来的内容也是公开的。
5. **网页是英文语境**。游戏 UI 全英文（jam 用），扫码进来的是 itch.io 的海外玩家 +
   少量国内玩家。页面主文案建议英文，中文可作辅助，别做成纯中文。
6. **手机优先**。扫码进来的 100% 是手机竖屏，桌面版是次要的。

## 8. 排障对照（省时间用）

| 现象 | 大概率原因 | 处理 |
| --- | --- | --- |
| 手机提示证书名称不匹配、证书是 `*.github.io` | GitHub 还没给自定义域名签出证书 | Pages 设置里 Remove 域名 → 重填 → Save，重启签发（DNS 别动） |
| 改完内容没变化 | 浏览器/CDN 缓存 | 无痕窗口、`Ctrl+F5`；确认 Actions 里有新构建 |
| 页面 404 | 文件名大小写不匹配（线上 Linux 区分大小写） | 检查路径拼写，`Index.html` ≠ `index.html` |
| 微信里白屏/转圈但浏览器能开 | 微信 X5 内核兼容性 | 用标准语法、少用新 API；点右上角「在浏览器打开」交叉验证 |
| 微信里显示「已停止访问该网页」 | 被微信风控拦截 | 申诉；与托管商无关 |
